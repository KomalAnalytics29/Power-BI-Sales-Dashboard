# 📊 Power BI Sales Dashboard

## 📌 Project Overview

This project is an interactive Sales Dashboard created using Microsoft Power BI. The dashboard analyzes sales data and presents key business information through interactive charts, graphs, cards, and slicers.

## 🎯 Project Objectives

* Analyze overall sales performance
* Compare sales across different regions
* Identify sales trends
* Analyze product performance
* Create an interactive and user-friendly dashboard

## 🛠️ Tools & Technologies

* Microsoft Power BI
* Microsoft Excel
* DAX
* Data Visualization

## 📈 Dashboard Features

The dashboard includes:

* Sales summary cards
* Column/bar charts
* Pie chart
* Sales trend graph
* Regional analysis
* Interactive slicers
* Product and category analysis

## 📂 Project Files

The repository contains the dataset, Power BI dashboard file, and dashboard screenshots.
